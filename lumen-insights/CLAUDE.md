# Lumen Insights

Python 3.11, stdlib only. Run the tests with `pytest -q`.

- Work from an issue. Branch `feature/<n>-<slug>` or `fix/<n>-<slug>` from `develop`.
- Before coding a story, write its spec with the spec-from-issue skill.
- Amounts are in euros with two decimals; use `Decimal`, never `float`.
